# Подпись установщика

Установщик KotaMusic не подписан. Из-за этого Windows показывает
«Неизвестный издатель», а SmartScreen на первых загрузках предупреждает
о неизвестном приложении. Это не ошибка сборки — так система относится
к любому файлу без репутации.

Ниже — что с этим можно сделать и чего это стоит.

## Что даёт подпись

| Способ | Стоит | «Неизвестный издатель» | SmartScreen |
| --- | --- | --- | --- |
| Без подписи | 0 ₽ | да | ругается, пока не наберётся репутация |
| Самоподписанный сертификат | 0 ₽ | да, если сертификат не установлен вручную | ругается так же |
| OV-сертификат | ~15 000 ₽ в год | нет | ругается первые недели |
| EV-сертификат | ~30 000 ₽ в год | нет | не ругается сразу |

Бесплатного способа убрать предупреждение полностью нет: репутацию
SmartScreen выдаёт файлу, который скачали достаточное число раз.

## Как подписать самоподписанным (бесплатно)

Такая подпись убирает «файл повреждён или изменён» и позволяет
проверить, что установщик собран нами и не подменён по дороге.

1. Создать сертификат (PowerShell, один раз):

   ```powershell
   $cert = New-SelfSignedCertificate -Type CodeSigningCert `
     -Subject "CN=KotaMusic" -CertStoreLocation Cert:\CurrentUser\My
   $password = ConvertTo-SecureString -String "пароль" -Force -AsPlainText
   Export-PfxCertificate -Cert $cert -FilePath kotamusic.pfx -Password $password
   ```

2. Положить `kotamusic.pfx` в секреты репозитория: содержимое файла в
   base64 — секрет `WINDOWS_CERT`, пароль — `WINDOWS_CERT_PASSWORD`.

3. Сборка установщика подхватит их сама: шаг уже есть в
   `.github/workflows/build-installer.yml` и включается, когда секреты
   заданы. Без секретов сборка идёт как раньше, без подписи.

## Про macOS

Там без сертификата Apple (99 $ в год) установщик запускается только
через «Открыть» в контекстном меню. Пока macOS выпускается как есть.
