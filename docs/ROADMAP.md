# Что дальше

Список задач проекта. Отмеченное сделано, остальное — по порядку важности.

## До первого релиза

- [ ] **Поддержка macOS.** Проверку целостности `app.asar` там хранит
      `Info.plist` (`ElectronAsarIntegrity`), а установщик сейчас умеет править
      только исполняемый файл Windows. Пока не сделано — выпускать честно
      с пометкой «Windows и Linux».
- [ ] **Выключить подробный журнал по умолчанию.** Сейчас мод пишет в файл
      каждый кадр, уходящий в Discord. Переключатель в настройках остаётся.
- [ ] **Отправлять статус своим клиентом, а не библиотекой.** Кадры совпадают
      байт в байт (проверено подменой Discord своим сокетом), поэтому копию
      `discord-rpc` из `mod/vendor` можно выбросить вместе с настройкой
      `useLibrary`.
- [ ] **Собрать установщик в настоящий файл.** `electron-builder` ещё ни разу
      не запускался: иконки, название, размеры окна всплывут при первой сборке.
- [ ] **Прогнать автосборку.** Workflow написаны, но проверяются только
      на живом репозитории.

## Желательно

- [ ] **Проверка обновлений мода изнутри клиента** — показывать «вышла новая
      версия» вместо того, чтобы человек узнавал случайно.
- [ ] **Чистка отладки**: диагностические каналы и перебор вариантов кадра
      (`mod/lib/bisect.js`) своё отработали.
- [ ] **Подпись установщика — бесплатным способом.** Самоподписанный
      сертификат убирает часть предупреждений, но SmartScreen всё равно
      будет ругаться на первых загрузках: репутация набирается скачиваниями.
      Платный сертификат — отдельное решение.

## Отложено

- [ ] **Скробблинг Last.FM.** Нужен ключ приложения Last.FM.

## Не делаем

- **Скачивание треков.** Требует расшифровки защищённого потока — это снятие
      технической защиты, а не сохранение того, что клиент получает открытым.
