# KotaMusic

Модификация десктопного клиента Яндекс Музыки: Discord Rich Presence,
скробблинг Last.FM, мини-плеер, глобальные горячие клавиши, своя папка кеша
и масштабирование интерфейса.

**Мод не заменяет подписку Яндекс Плюс** и не снимает защиту с треков.

## Как это устроено

В репозитории лежит только наш код: слой мода (`mod/`) и описания врезок
(`patches/`). Код Яндекса мы не храним и не распространяем в исходниках —
сборка скачивает официальный установщик с серверов Яндекса, достаёт из него
`app.asar`, накладывает патчи и пакует обратно.

```
mod/       — код мода, попадает в app.asar отдельной папкой
patches/   — врезки в код клиента; каждая умеет сообщить, что не применилась
scripts/   — сборка и работа с официальной раздачей клиента
installer/ — GUI-установщик (в работе)
```

## Сборка

```bash
npm install
node scripts/build.js --platform=linux   # linux | win32 | darwin
```

Результат — `dist/app.asar` и `dist/build-info.json` с версией клиента и
отчётом по патчам. Если хоть одна врезка не легла, сборка падает и релиз не
выкладывается: значит, Яндекс изменил код и нужна правка.

Для распаковки установщиков нужны `ar` и `tar` (Linux) и `7z` (Windows, macOS).
